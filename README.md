# Multimodal Product Reranker

> Does adding product-image information improve product search ranking?

A research project that evaluates whether incorporating CLIP image embeddings alongside text features improves product search reranking, using the Amazon ESCI dataset and SQID image embeddings.

## Quick Start

```bash
make setup   # install dependencies
make all     # run the full pipeline
```
